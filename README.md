# The Flourishing Community — One-page Website

Static landing site for The Flourishing Community, The Flourishing Letter, The Flourishing Forum and The Flourishing Cohort.

## Stack
- Static HTML/CSS/JS
- Tally newsletter signup form
- Vercel deployment
- Cloudflare DNS and email routing
- Systeme.io newsletter delivery

## Deployment
Import this repository into Vercel. No build command is required. The project root contains `index.html`.

## Domain
Primary: `theflourishing.com.ng`
Recommended redirect: `www.theflourishing.com.ng` → `theflourishing.com.ng`
